# Security Policy — CareGraph AI

## 1. Project Disclaimer & Clinical Scope

> [!IMPORTANT]
> **CareGraph AI is an AI engineering portfolio, demonstration, and research architecture.**
>
> - **Not a Medical Device**: CareGraph AI is **NOT** a certified medical device, clinical diagnostic tool, or medical decision support system. It must **NOT** be used as a substitute for professional medical judgment, diagnosis, or treatment.
> - **Synthetic / Demo Data Only**: All datasets, patient profiles, clinical notes, and encounter timelines included in this repository or generated by default seeds are entirely **synthetic**. No real Protected Health Information (PHI) or Personally Identifiable Information (PII) is stored or tracked in this codebase.
> - **Non-Production Demonstration**: Any cloud deployment configurations (Docker, Azure Container Instances) are provided for architectural demonstration purposes.

## 3. Reporting a Vulnerability

We take the security and integrity of CareGraph AI seriously. If you discover a security vulnerability, please report it responsibly:

### Recommended: GitHub Private Vulnerability Reporting
1. Navigate to the repository on GitHub: [chandeshwar-prasad/caregraph-ai](https://github.com/chandeshwar-prasad/caregraph-ai).
2. Click on the **Security** tab.
3. Under **Reporting**, click **Report a vulnerability** to open a private advisory draft.

### Direct Contact
If private vulnerability reporting is unavailable, please email the maintainer directly at:
- **Maintainer**: Chandeshwar Prasad
- **GitHub**: [@chandeshwar-prasad](https://github.com/chandeshwar-prasad)

Please provide:
- A description of the issue and potential impact.
- Step-by-step instructions or proof-of-concept (PoC) to reproduce.
- Any relevant logs, payloads, or screenshots.

### Response Timeline
- **Initial Response**: Within 48 hours of notification.
- **Triage & Status Update**: Within 5 business days.
- **Resolution / Disclosure**: Once a fix is verified and merged.

## 4. Security & Hygiene Best Practices in CareGraph AI

The CareGraph AI codebase adheres to the following baseline security controls:

- **Secret Management**: No API keys, credentials, or JWT signing secrets are committed to version control. Environment configurations are loaded strictly through environment variables (`.env` is excluded via `.gitignore` and `.dockerignore`).
- **Authentication & RBAC**: API endpoints enforce server-side role-based access control (e.g., patient, admin) and require signed JWT bearer tokens.
- **Continuous Integration Hygiene**: Automated CI workflows enforce zero-secret leakage checks on `.env.example` and verify that no local `.env` files are tracked.
- **Container Packaging & Secret Hygiene**: Docker packaging employs minimal slim base images (python:3.11-slim), container health checks, and strict exclusion of local credentials/secrets from image layers.
